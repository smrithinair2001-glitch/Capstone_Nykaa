# Reverse-Pickup Eligibility

Reverse pickup, where a courier collects the item from the customer's address instead of the customer shipping it back themselves, is available for all pin codes where Nykaa also offers forward (outbound) delivery. It is not available for Home category items above 20 kg or for assembled furniture, which instead require the customer to use a manufacturer-arranged pickup described separately on the order confirmation. A reverse pickup must be scheduled within the category's return window (see the return-window policy) and the item should be packed in its original box with all accessories; pickups with visibly missing packaging are flagged for additional quality review rather than refused outright. If two reverse-pickup attempts fail because no one was available at the address, the return request is automatically cancelled and the customer must raise a fresh return request.
