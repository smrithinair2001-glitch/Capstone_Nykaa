n_orders = 60
80th percentile of days_since_created = 22 days
  -> escalation_score if that order is ALSO delayed  : 0.6*1 + 0.4*(22/30) = 0.8933
  -> escalation_score if that order is NOT delayed   : 0.6*0 + 0.4*(22/30) = 0.2933
Chosen ESCALATION_THRESHOLD = 0.5
  -> 16.67% of the 60 generated orders currently cross this threshold.
